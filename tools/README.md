# tools — 업무 보드 점검 도구

## check-overflow.mjs — 긴 글 넘침·겹침 검사

카드 상세 창에서 긴 제목이 닫기(×) 버튼을 덮은 일(2026-10-21, 고친 커밋 `5bef441`)과
같은 종류의 문제가 다시 생기면 잡아 주는 검사입니다.

```bash
node tools/check-overflow.mjs
```

- 필요한 것: node 22 이상, 맥의 Google Chrome. 따로 설치할 것은 없습니다.
- 진짜 `board/index.html`·`board/board.css` 로 시험 화면을 만들고, 아주 긴 한국어 제목·띄어쓰기 없는
  주소·태국어·긴 영어 단어·긴 이름을 채워 넣습니다(`board.js` 는 쓰지 않음 — 서버 없이 돈다).
- 폭 380·768·1280px 에서 보드, 카드 상세 창, 대기 창, 추가 창, 확인 창을 하나씩 열어 봅니다.
- 보는 것
  1. 버튼과 글자가 겹치는지(글자의 실제 줄 영역 기준), 버튼끼리 겹치는지, 버튼이 다른 것에 가려지는지
  2. 칸 밖으로 가로로 넘치는지, 페이지에 가로 스크롤이 생기는지(스크롤로 보라고 만든 칸은 뺌)
  3. 창이나 창 안의 버튼이 화면·창 밖으로 나가는지
- 결과: 문제가 없으면 `이상 없음` 과 종료 코드 0, 있으면 어디·어떤 폭·어떤 화면인지 적고 종료 코드 1.
  도구 자체가 못 돌면(Chrome 없음 등) 종료 코드 2.

### 선택 옵션

| 옵션 | 뜻 |
| --- | --- |
| `--css <파일>` | 다른 CSS 로 검사(예: 옛 버전과 비교) |
| `--html <파일>` | 다른 HTML 로 검사 |
| `--widths 380,768,1280` | 검사할 폭 |
| `--height 800` | 화면 높이 |
| `--keep` | 만든 시험 화면 파일을 지우지 않고 위치를 알려 줌(브라우저로 열어 직접 볼 때) |
| 환경변수 `CHROME_PATH` | Chrome 위치가 다를 때 |

옛 버전과 비교하는 예:

```bash
git show 5bef441~1:board/board.css > /tmp/old.css
node tools/check-overflow.mjs --css /tmp/old.css   # × 겹침을 잡아내야 한다
```

### 고칠 때 참고

- CSS·HTML 을 고친 뒤 올리기 전에 한 번 돌립니다.
- 새 창이나 버튼을 만들면 이 파일 안 `inPage()` 의 채우기 함수(`fillDetail` 등)에도 긴 글을 넣어 둡니다.
- 시험 내용은 모두 지어낸 글입니다. 이 저장소는 공개되므로 실제 이름·주소·비밀값을 넣지 않습니다.
